# OSSM Web Control

Control your OSSM over Bluetooth from your browser with
[OSSM Web Control](https://ossm-web.forestpuppy.pet/), by
[ReadieFur](https://github.com/ReadieFur).

![OSSM Web Control landscape controls preview](https://raw.githubusercontent.com/ReadieFur/OSSM-Web-Control/main/docs/iPhone_Landscape.gif)

Adjust speed and range, choose custom patterns and sensation, and recalibrate
the rail. Install it as a progressive web app for offline use on supported
devices.

Requires **OSSM firmware v1.0.50 or newer** and a Bluetooth-capable browser:
Chrome, Edge, or Brave on desktop; Chrome on Android; or
[Bluefy on iPhone](https://apps.apple.com/us/app/bluefy-web-ble-browser/id1492822055).

> **Safety:** BLE controls command real motion. Use at your own risk; verify
> stop behavior and motion limits before use, and keep a physical way to stop
> the machine within reach.
