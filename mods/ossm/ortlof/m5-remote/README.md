# OSSM M5 Remote

A wireless remote-control platform for the OSSM (and other ESP-controlled toys),
built on the [M5Stack](https://m5stack.com/) CoreS3 / Core2. It gives you a
touchscreen remote for speed, depth, and stroke instead of the wired cable
remote.

## Important

- It does **not** work with the official OSSM firmware — it requires the
  [`ortlof/OSSM-Stroke`](https://github.com/ortlof/OSSM-Stroke) firmware branch.
- Flashing back to official firmware restores the original cable remote.
- Build instructions, PCB files, BOM, and supported M5Stack models are all in
  the [upstream repo](https://github.com/ortlof/OSSM-M5-Remote).
