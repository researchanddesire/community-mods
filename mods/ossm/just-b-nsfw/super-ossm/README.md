# Super-OSSM

A modular redesign of the OSSM by
[just_b](https://github.com/just-b-nsfw) (GitHub: `just-b-nsfw`).

**External / linked mod:** CAD, print files, BOMs, and assembly instructions
are maintained in the [upstream repository](https://github.com/just-b-nsfw/Super-OSSM).

![Super-OSSM with Capstan drive](img/super-ossm.png)

## Design options

This machine supports 42AIM, 57AIM, 60AIM series, and 60AIM40F motors;
R+D and ALT PCBs; MGN12, MGN15, and HGR20 rails; and belt or Capstan drives.
The legacy iHSV motor is explicitly unsupported.

**Capstan drive support:** Super-OSSM includes an alternative drive option
for SaladDressing's Capstan drive system.

The enclosure uses a twist-lock for service access. Fixed and folding mounting
clamps and a stroker add-on are available upstream. Check the current build
guide and BOM before selecting parts.
