# OSSM Possum

A Bluetooth remote-control project for
[KinkyMakers OSSM firmware](https://github.com/KinkyMakers/OSSM-hardware). It
runs as a native iOS or Android app, as a web page, or as an offline PWA,
giving you touchscreen control of speed, depth, and stroke — no cost or ads.

## Highlights

- Works with **KinkyMakers OSSM firmware** — no firmware changes required.
- Native **iOS** and **Android** apps, plus a **web / PWA** option for offline use.
- Touchscreen control of speed, depth, and stroke over Bluetooth.
