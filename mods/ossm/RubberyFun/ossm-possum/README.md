# OSSM Possum

A Bluetooth remote-control app for the **stock** firmware of the
[Kinky Makers OSSM](https://www.researchanddesire.com/pages/ossm). It runs as a
native iOS or Android app, as a web page, or as an offline PWA, giving you
touchscreen control of speed, depth, and stroke — no cost, no ads, no strings
attached.

## Highlights

- Works with **stock OSSM firmware** — no firmware changes required.
- Native **iOS** and **Android** apps, plus a **web / PWA** option for offline use.
- Touchscreen control of speed, depth, and stroke over Bluetooth.
