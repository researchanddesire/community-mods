# Lockbox ecosystem projects

Projects related to the
[Lockbox ecosystem](https://github.com/researchanddesire/Lockbox), including
variants, accessories, hardware, software, and tools.

Index an upstream project or host one here at the catalog path
`mods/lockbox/<project_slug>/`. Project credit lives in the `author` metadata
field, and both contribution paths are equal in the hub.

See the [contributing guide](../../CONTRIBUTING.md) and the
[sample entry](../../examples/hosted-ossm-project/).
